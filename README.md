# 🚀 Tarefus - Gestão Simples de Tarefas

Um sistema web **direto, rápido e sem complicações** para gestão de tarefas em pequenas empresas, pensado especialmente para colaboradores e equipes que buscam produtividade sem a complexidade excessiva do Trello ou ClickUp.

---

## ✨ Funcionalidades Principais

- 👤 **Login e Troca Rápida de Usuário**: Alterne entre colaboradores em 1 clique ou cadastre novos membros.
- 🏢 **Quadros por Área da Empresa**: Visualize tarefas por departamento (*Vendas*, *Operações*, *Marketing*, *Administrativo*) ou veja todas as áreas consolidadas.
- 📋 **Kanban Intuitivo (3 Colunas)**:
  - **A Fazer**
  - **Fazendo (Em Andamento)**
  - **Concluído**
- 🔀 **Arrastar e Soltar (Drag & Drop)**: Mova cartões livremente entre as colunas com mouse no computador ou toque no celular.
- 🃏 **Cartões com Tudo que Importa**:
  - Título claro
  - Descrição detalhada opcional
  - Responsável com avatar e iniciais
  - Prazos com alerta visual (*Hoje*, *Atrasado*, *Data*)
  - Checklist interativo com barra de progresso em tempo real
  - Conclusão rápida com 1 clique direto no cartão
- 🎯 **Tela "Minhas Tarefas"**: Visão exclusiva para o colaborador logado focar no que precisa fazer hoje, sem distrações.
- 🔍 **Busca & Filtros Rápidos**: Encontre qualquer tarefa ou filtre por responsável instantaneamente.
- 💾 **Persistência Local (LocalStorage)**: Todos os dados permanecem salvos no navegador, com opção de resetar para dados de exemplo a qualquer momento.
- 📱 **100% Responsivo**: Interface limpa e adaptada para computadores, tablets e smartphones.

---

## 🛠️ Tecnologias Utilizadas

- **React 19** + **TypeScript**
- **Vite** (Build ultra-rápido)
- **Tailwind CSS v4** (Design moderno e minimalista)
- **Lucide Icons** (Ícones limpos e consistentes)
- **@hello-pangea/dnd** (Arrastar e soltar suave)

---

## 🚀 Como Executar

1. Instale as dependências:
```bash
npm install
```

2. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

3. Acesse no navegador:
```
http://localhost:5173
```
